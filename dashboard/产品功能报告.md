## 执行摘要

Dashboard是一款专为智能交通信号控制设计的综合性可视化管理平台。系统整合了实时监控、模型训练、数据分析、算法对比四大核心功能模块，为交通管理人员、科研人员和系统运维人员提供一站式解决方案。通过直观的Web界面，用户可以实时掌握路网运行状态，评估不同算法效果，优化交通信号控制策略。

## 三、核心功能模块

### 模块一：模型训练 🎓

#### 3.1.1 功能定位

提供完整的PPO模型训练管理能力，让非算法专家也能轻松训练高质量的交通信号控制模型。

#### 3.1.2 核心功能

**训练配置**
- 场景选择：支持多种路网场景（杭州4×4、自定义路网等）
- 参数设置：
  - 训练轮数（epochs）：10-5000轮
  - 学习率（learning_rate）：1e-5 到 1e-3
  - 批大小（batch_size）：16/32/64/128
  - 其他超参数：gamma、clip_ratio、熵系数等

**训练监控**
- 实时进度显示：当前epoch/总epoch
- 损失曲线：
  - 策略损失（Loss_pi）
  - 价值损失（Loss_vf）
  - 策略熵（Pi_Entropy）
- 性能指标：平均奖励、收敛速度
- 日志输出：详细的训练日志实时查看

**训练控制**
- 启动训练：一键启动后台训练任务
- 暂停/恢复：支持训练中断与恢复
- 停止训练：安全终止训练进程
- 保存checkpoint：自动保存训练节点

#### 3.1.3 业务价值

| 价值点 | 说明 | 收益 |
|--------|------|------|
| **降低技术门槛** | 图形化配置替代代码编写 | 非技术人员可独立操作 |
| **提升训练效率** | 实时监控及时发现问题 | 缩短30%调试时间 |
| **保证模型质量** | 自动保存最优checkpoint | 避免训练成果丢失 |

#### 3.1.4 使用场景

**场景1：新模型训练**
```
用户：研究人员
需求：针对新路网训练PPO模型
操作流程：
  1. 选择训练场景（杭州4×4）
  2. 设置训练参数（100轮，学习率0.0001）
  3. 点击"开始训练"
  4. 监控训练曲线，观察收敛情况
  5. 训练完成，自动保存模型
结果：获得针对该场景优化的控制模型
```

**场景2：超参数调优**
```
用户：算法工程师
需求：优化模型性能
操作流程：
  1. 加载已有模型继续训练
  2. 调整学习率进行精调
  3. 对比不同参数的训练曲线
  4. 选择最优参数组合
结果：模型性能提升15%
```

### 模块二：交通数据 📊

#### 3.2.1 功能定位

提供完整的交通数据管理能力，支持数据查询、分析、可视化和导出，为决策提供数据支撑。

#### 3.2.2 核心功能

**数据查询**
- 时间范围筛选：
  - 快捷选项：最近1小时、今天、本周
  - 自定义时间段
- 空间范围筛选：
  - 全路网
  - 指定路口列表
  - 区域选择
- 数据类型：
  - 车辆数据：位置、速度、等待时间
  - 车道数据：流量、占有率、排队长度
  - 信号灯数据：相位、切换频率、周期

**数据分析**
- 趋势分析：时间序列图，识别高峰低谷
- 分布统计：直方图、箱线图，了解数据分布
- 相关性分析：热力图，发现变量关系
- 对比分析：多场景、多时段对比

**数据可视化**
- 折线图：流量、速度随时间变化
- 柱状图：各路口流量对比
- 热力图：拥堵时空分布
- 散点图：变量关系展示

**数据导出**
- 格式支持：CSV、JSON、Excel
- 导出范围：全部数据或筛选结果
- 用途：进一步分析、报告制作

#### 3.2.3 技术特性

- **数据源**：TDengine时序数据库，支持高速读写
- **数据量**：单次查询支持百万级记录
- **响应速度**：查询响应<1秒
- **实时性**：数据延迟<100ms

#### 3.2.4 业务价值

| 价值点 | 说明 | 收益 |
|--------|------|------|
| **数据驱动决策** | 基于真实数据分析问题 | 决策准确率提升40% |
| **发现隐藏规律** | 可视化揭示数据模式 | 识别优化机会 |
| **报告自动化** | 一键导出分析结果 | 节省80%报告制作时间 |

### 模块四：对比实验 📈

#### 3.4.1 功能定位

提供自动化的算法对比实验能力，支持多算法、多场景、多次重复的批量测试，生成专业的对比报告。

#### 3.4.2 核心功能

**实验创建**
- 基本信息：
  - 实验名称和描述
  - 实验目标和假设
- 场景配置：
  - 选择测试场景（单个或多个）
  - 设置仿真参数（时长、流量倍率）
- 算法配置：
  - 选择对比算法列表
  - PPO（指定模型路径）
  - MaxPressure
  - FixedTime
  - GreenWave
  - Transformer-PPO
- 实验设置：
  - 重复次数（建议5-10次）
  - 评估指标选择
  - 显著性检验参数

**实验运行**
- 自动化执行：
  - 按配置顺序运行所有测试
  - 每个算法×每个场景×重复次数
- 进度监控：
  - 实时进度条（已完成/总任务数）
  - 当前运行的任务信息
  - 预计剩余时间
- 中途控制：
  - 暂停实验
  - 恢复实验
  - 提前终止

**结果分析**
- 原始数据：
  - 每次运行的详细指标
  - 仿真日志和统计数据
- 统计分析：
  - 均值、标准差、置信区间
  - 箱线图展示数据分布
  - 显著性检验结果（p-value）
- 对比可视化：
  - 柱状图：各算法指标对比
  - 折线图：性能随时间变化
  - 雷达图：多维度综合对比
  - 热力图：场景-算法性能矩阵

**报告生成**
- HTML报告：
  - 完整的实验配置
  - 详细的结果分析
  - 可交互的图表
  - 结论和建议
- PDF报告：适合打印和分发
- Excel数据表：原始数据导出

## 四、中央地图可视化区

### 4.1 功能定位

中央地图是Dashboard的核心展示区域，实时呈现路网状态，提供直观的交通态势感知能力。

### 4.2 核心功能

#### 4.2.1 路网展示

**静态元素**
- 道路（Edge）：
  - 显示道路几何形状
  - 线条宽度可配置
  - 支持单向/双向道路
- 路口（Junction）：
  - 节点圆点标记
  - 大小可调节
  - 区分有无信号灯
- 连接（Connection）：
  - 显示车道连接关系
  - 转向关系可视化

**动态元素**
- 车辆（可选显示）：
  - 实时位置更新
  - 不同车辆类型区分
  - 运动轨迹显示
- 信号灯状态：
  - 绿灯相位高亮
  - 红灯相位灰显
  - 黄灯过渡状态

#### 4.2.2 拥堵可视化

**颜色编码**
```
拥堵级别    颜色      拥堵度范围    说明
────────────────────────────────────────
顺畅        绿色      0.0 - 0.3     交通流畅
轻度拥堵    黄色      0.3 - 0.6     开始缓行
中度拥堵    橙色      0.6 - 0.8     明显拥堵
严重拥堵    红色      0.8 - 1.0     严重拥堵
```

**拥堵计算算法**
- 综合考虑：
  - 速度因子（50%权重）：速度越低拥堵越严重
  - 车辆数因子（25%权重）：车辆越多拥堵越严重
  - 停车因子（25%权重）：停车越多拥堵越严重
- 实时更新：每秒刷新一次

#### 4.2.3 交互操作

**缩放控制**
- 放大：点击[+]按钮或滚轮向上
